## 下单前需要知道的细节与隐藏限制

**流量用完后的处理**
ZoroCloud 的流量是按月计算的（比如 1TB/月），用完后会限速或停机。如果你的应用流量需求大（比如视频站、下载站），提前算一下够不够用。入门款套餐流量普遍不大，真正需要大流量的场景可能得选 Ultra 或 Elite 级别。流量用完可以联系客服购买额外流量包，但价格不算便宜。

**Windows 系统的内存限制**
ZoroCloud 的云服务器支持 Linux 各发行版（CentOS、Ubuntu、Debian 等），但 Windows Server 有内存要求：**2GB 内存及以上套餐才支持 Windows 系统**。1GB 内存的入门款只能跑 Linux。如果你确实需要 Windows 环境，至少选 2GB 内存的标准款。

**退款政策细节**
官方说的"24 小时退款"有前提：无滥用情况下。什么算滥用？大量消耗流量、频繁开关机、违规操作（比如发垃圾邮件、扫描攻击）都可能被判定为滥用。正常使用测试网络质量、搭建应用这些操作不会有问题。退款金额可以原路退回。

独立服务器支持先测试后付款，这一点比较厚道。

**续费价格**
官方多处提到"循环优惠，续费同价"，意思是首次购买和续费都能用优惠码。这一点比很多 VPS 商家厚道，不少商家首购便宜、续费涨价。但注意优惠码本身可能会过期或调整（比如从 6.8 折变成 7.5 折），续费时记得再确认一下当前可用的优惠码。

**IP 数量与多 IP 需求**
